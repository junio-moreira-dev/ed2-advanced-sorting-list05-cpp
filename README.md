# 📘 ED2 — Advanced Sorting — List 05

Practice exercises for **Data Structures II** — divide and conquer with **Merge Sort** and **Quick Sort** in C++ (direct merge of two sequences, recursive trace, record sorting with tie-break, swap counting with Lomuto and Hoare, and median-of-three pivot).

> **Note:** `main.cpp` at the project root is the default file created by CLion. It is **not part of the exercises**. `cmake-build-debug/` is generated by the IDE.

Each exercise is solved in its own file inside `src/`. Every `Exer*.cpp` file is **self-contained** (has its own `main()`) and follows the same pattern:

| Part | Responsibility |
|---|---|
| `class Solution` | Implements the algorithm. |
| `main()` | Runs the test cases and prints the results. |

| # | File | Problem | Technique | Complexity |

| 1 | `Exer01_TwoPointersMerge.cpp` | Merge two sorted sequences into one sorted sequence | Two pointers | O(N + M) |

---

## ⚠️ Read the Problem Statement Carefully

- **Exercise 1:** implement only the **merge** of two sorted vectors (no recursion and no `std::sort`). When one vector ends, the rest of the other one goes to the end of the result.
- **Exercise 2:** split the range at `⌊(ini + fim) / 2⌋`. Print **one line per finished merge**, in the order the merges happen, and the `[Final]:` line at the end.
- **Exercise 3:** the comparison rule has two keys: higher score first and, on a tie, alphabetical order of the name (`string` comparison, so uppercase letters come before lowercase ones).
- **Exercise 4:** count only **effective swaps** (`i != j`), on two identical copies of the vector. The totals depend on the pivot choice of each scheme, so use the examples of the statement to validate your implementation.
- **Exercise 5:** the pivot is the **median** of `nums[ini]`, `nums[(ini + fim) / 2]` and `nums[fim]`. Print the pivot chosen in the **first call** (range `[0..N-1]`). N is at least 3.

## ⚠️ Leia o Enunciado com Atenção

- **Exercício 1:** implemente apenas a **intercalação** de dois vetores ordenados (sem recursão e sem `std::sort`). Quando um vetor acaba, o restante do outro vai para o fim do resultado.
- **Exercício 2:** divida o intervalo em `⌊(ini + fim) / 2⌋`. Imprima **uma linha por intercalação concluída**, na ordem em que elas acontecem, e a linha `[Final]:` no fim.
- **Exercício 3:** a regra de comparação tem duas chaves: maior pontuação primeiro e, no empate, ordem alfabética do nome (comparação de `string`, então as letras maiúsculas vêm antes das minúsculas).
- **Exercício 4:** conte apenas as **trocas efetivas** (`i != j`), em duas cópias idênticas do vetor. Os totais dependem da escolha de pivô de cada esquema, então use os exemplos do enunciado para validar a sua implementação.
- **Exercício 5:** o pivô é a **mediana** de `nums[ini]`, `nums[(ini + fim) / 2]` e `nums[fim]`. Imprima o pivô escolhido na **primeira chamada** (intervalo `[0..N-1]`). N é no mínimo 3.
